# 工业过程数字孪生与异常根因推理服务

纯后端 Node.js + TypeScript + Fastify 项目，使用内存状态运行，不依赖 Docker、数据库或消息队列。

## 运行

```bash
npm install
npm test
npm start
```

## 业务闭环

设备拓扑版本 → 遥测接入 → 时间序列重放 → 阈值异常检测 → 拓扑影响分析 → 根因候选 → 工单状态机 → 审计追踪。

关键不变量：拓扑版本连续且按生效时间选择；遥测接入按 eventId 幂等去重（重试复用既有结果，非法请求不占序列号），事件序列号在实例内唯一且单调递增；遥测事件按业务时间和序列号重放，事件索引（GET /telemetry/events/:id）、审计引用与回放结果一一对应；工单只能沿合法状态机迁移；所有重要操作产生审计记录。
